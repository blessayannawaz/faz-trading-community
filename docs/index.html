Add a version

Each save creates a separate version. Existing source files stay intact.

Your library lives on GitHub.

  1. Connect your private library.

    Use Connect GitHub and enter an access key for your private data repository. Your GitHub browser login alone cannot give this website permission to save.

  2. Create an indicator.

    Use New indicator, then Add version. Upload a Pine file or paste code, and add screenshots.

  3. Save to GitHub.

    Wait for the saved message. Each save writes the source, screenshots and catalogue together in your private repository.

  4. Return from any computer.

    Open this website and connect with your access key. Refresh library loads changes saved elsewhere.

Internet is required. Your access key is held only in the open page and must be entered again after a reload. Unsaved form changes are not uploaded.

Versions remain in GitHub history. Archive hides an indicator without deleting its files. Use GitHub to manage access and backups.
GITHUB EDITION

Connect your private library

Your indicators, source code and screenshots will be saved in blessayannawaz/faz-trading-library-data.

First time? Create an access key
  1. Open GitHub access-key settings ↗.
  2. Name it FAZ Library and choose an expiration date.
  3. Under Repository access, choose Only select repositories → faz-trading-library-data.
  4. Add repository permission Contents: Read and write. Metadata read access is automatic.
  5. Generate the token yourself, then paste it here. Never put it in a chat or repository file.

The key is sent only to api.github.com and kept only in this open page. It is not stored on disk, in a cookie or in your repository.
